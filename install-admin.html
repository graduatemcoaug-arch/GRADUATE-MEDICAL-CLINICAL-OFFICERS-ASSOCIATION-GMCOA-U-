Quick Access to Your Admin Tools

Add your main admin page directly to your home screen for one-tap access — no need to type the address each time. Since admin tools require login, this creates a direct shortcut rather than the general public app.

📱 Android (Chrome)

  1. Open admin.html (this exact page)
  2. Tap the ⋮ menu (top-right corner of Chrome)
  3. Tap "Add to Home screen"
  4. Tap "Add" to confirm

🍎 iPhone (Safari)

  1. Open admin.html (this exact page) in Safari
  2. Tap the Share icon (square with an arrow, at the bottom)
  3. Scroll down and tap "Add to Home Screen"
  4. Tap "Add" in the top-right corner

Must be done in Safari, not Chrome, on iPhone.

This creates a shortcut icon that opens straight to the Applications admin tool — from there, the nav bar links to Finance, Governance, Communications, Directory, Elections, Events, AGM/EGM, and Secretariat, so you only need one shortcut to reach everything. You'll still need to log in with your admin credentials as usual.

Prefer to start on a different tool instead? Repeat the same steps from secretariat.html, finance.html, or any other admin page directly.
